# 🚀 MERN Development Track

A structured and continuously evolving repository documenting my journey through **MERN Stack Development** — from web fundamentals and frontend engineering to backend architecture, database design, REST APIs, middleware, and full-stack application development.

The repository is organized as a progressive learning track, with each module focused on a specific technology or backend concept and supported by hands-on implementations.

## 📂 Repository Structure

| Module | Focus Area |
|--------|------------|
| `01_HTML` | Semantic HTML, document structure, forms, media, and web fundamentals |
| `02_CSS` | Selectors, layouts, responsive design, styling, animations, and UI fundamentals |
| `03_javaScript` | ES6+, DOM manipulation, functions, asynchronous JavaScript, APIs, and core programming concepts |
| `04_React` | Components, props, state, hooks, lifecycle concepts, and React-based UI development |
| `05_Tailwind CSS` | Utility-first styling, responsive layouts, reusable UI patterns, and modern frontend design |

| `07_mongodb` | MongoDB fundamentals, Mongoose, schemas, models, queries, and database operations |
| `08_MiddleWare` | Custom middleware, request processing, validation, and centralized error handling |

## 🧱 Development Approach

The repository follows a **module-based and incremental learning approach**.

Each module is designed to:

1. Introduce a core technology or concept
2. Implement the concept through practical code
3. Build small exercises or projects around it
4. Gradually integrate previously learned concepts
5. Move toward production-oriented full-stack development

This makes the repository useful not only as a learning log, but also as a reference for revisiting individual concepts.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/sachinkumar-git/MERN-Development-Track.git
```

Navigate to the project:

```bash
cd MERN-Development-Track
```

Each module contains its own implementation and can be explored independently.

For backend modules that contain a `package.json`, install dependencies using:

```bash
npm install
```

Then run the corresponding project using the scripts defined in its `package.json`.
